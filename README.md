# Python-Power-UP
Este repositório contém um projeto em Python desenvolvido para praticar automação de tarefas utilizando a biblioteca PyAutoGUI.

O sistema realiza o login em uma página web e cadastra automaticamente produtos a partir de uma base de dados em formato CSV, preenchendo campos como código, marca, tipo, categoria, preço, custo e observações.

# Estrutura do Projeto

codigo.py → Script principal que automatiza o processo de login e cadastro de produtos no sistema.

auxiliar.py → Código auxiliar para capturar a posição do mouse na tela (usado na automação com PyAutoGUI).

main.py → Script padrão gerado pelo PyCharm, mantido como referência.

produtos.csv → Base de dados com os produtos que serão cadastrados automaticamente.

# Tecnologias Utilizadas

Python 3

PyAutoGUI

Pandas

OS / Time

# Objetivo

Este projeto tem como foco o aprendizado prático de automação com Python, explorando a manipulação de arquivos, leitura de dados com Pandas e interação automatizada com interfaces gráficas.
