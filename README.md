# Python-Power-UP  
## Task Automation with PyAutoGUI

This repository contains a **Python automation project** developed to practice task automation using the **PyAutoGUI** library.

The system performs an **automatic login on a web page** and **automatically registers products** based on data from a CSV file, filling in fields such as product code, brand, type, category, price, cost, and additional notes.

---

## Project Overview

The main goal of this project is to automate repetitive tasks by simulating user interactions with a graphical interface, demonstrating how Python can be used to increase productivity and reduce manual effort.

---

## Project Structure

- **codigo.py** – Main script responsible for automating the login process and product registration  
- **auxiliar.py** – Helper script used to capture mouse cursor positions on the screen (used in PyAutoGUI automation)  
- **main.py** – Default script generated by PyCharm, kept for reference  
- **produtos.csv** – Dataset containing the products to be automatically registered  

---

## Technologies Used

- Python 3  
- PyAutoGUI  
- Pandas  
- OS  
- Time  

---

## Project Objective

This project focuses on hands-on learning of **Python automation**, exploring file manipulation, data reading with Pandas, and automated interaction with graphical user interfaces. It is ideal for demonstrating automation concepts and practical Python skills.

## How to Use

1. Clone this repository:
```bash
git clone https://github.com/your-username/repository-name.git
```
Navigate to the project directory:
```
cd repository-name
```

Install the required dependencies:
```
pip install pandas pyautogui
```

Adjust mouse positions using the helper script:
```
python auxiliar.py
```

Run the main automation script:
```
python codigo.py
```
## Important Notes

- UI automation depends on screen resolution and interface positioning.

- Any change in layout may require recalibration of mouse coordinates.

- Use this project only on systems and applications where automation is allowed.
